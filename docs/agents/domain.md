# Domain Docs

This is a single-context repository.

## Before exploring

Read:

- `CONTEXT.md`
- Relevant ADRs under `docs/adr/`

If either is absent, proceed silently.

## Layout

```text
/
├── CONTEXT.md
└── docs/
    └── adr/
```

## Vocabulary

Use the canonical terms defined in `CONTEXT.md`. Do not substitute terms listed under `_Avoid_`.

If a required concept is missing, either reconsider the new terminology or record the gap for domain modeling.

## ADR conflicts

If proposed work contradicts an existing ADR, surface the conflict explicitly instead of silently overriding the decision.
